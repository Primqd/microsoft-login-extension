# Google Extension Testing

simple google extension for learning about google extension api. automatically logs into the microsoft internet login portal thingy

## How to Use

1. Load the extension in Chrome:
   - Open Chrome and navigate to `chrome://extensions/`.
   - Enable "Developer mode".
   - Click "Load unpacked" and select the project folder.
2. The project should automatically read the username and password from the login screen.
3. If you need to manually edit the username and password, you can click the extension icon and manually edit them there.
